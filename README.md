# Telegram_bot

## Описание проекта
**Telegram_bot** — это телеграмм-бот, который управляет списком сотрудников с использованием базы данных SQLite. Бот позволяет:
- Просматривать списки сотрудников по сменам (1, 2, 3, и 4 смена).
- Просматривать информацию о сотрудниках: ФИО, номер телефона, должность, смена, Telegram ID, дата рождения, табельный номер, статус больничного, отпуск, номер удостоверения, адрес проживания.
- Узнавать, кто из сотрудников находится в отпуске или на больничном.
- Добавлять новых сотрудников, редактировать больничные и отпуска через интерфейс бота.
- Удалять сотрудников из базы данных.
- Проверять, кто использует бота, командой `/humans`, которая выводит список пользователей бота и их Telegram ID.

Чтобы начать работу с ботом, необходимо ввести пароль: `549`.

## Установка

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/ваш_логин/Telegram_bot.git
   cd Telegram_bot

2. **Создайте виртуальное окружение**:
    python -m venv venv

3. **Активируйте виртуальное окружение**:
   На Windows:
     venv\Scripts\activate

   НА macOS и Linux:
     source venv/bin/activate

4. **Установите зависимости**:
   pip install -r requirements.txt

5. **Настройте бота**:
   Создайте нового бота в Telegram через BotFather.
   Получите токен для бота и добавьте его в ваш код (например, в переменную TOKEN или файл конфигурации).

6. **Использование**:
  Бот поддерживает меню, состоящее из 8 пунктов:
  
  СМЕНА 1 — Список сотрудников первой смены.
  СМЕНА 2 — Список сотрудников второй смены.
  СМЕНА 3 — Список сотрудников третьей смены.
  СМЕНА 4 — Список сотрудников четвертой смены.
  БОЛЬНИЧНЫЕ — Список сотрудников на больничном.
  ОТПУСК — Список сотрудников в отпуске за указанный месяц.
  ДОБАВИТЬ РАБОТНИКА — Добавление нового сотрудника в базу данных.
  УДАЛИТЬ РАБОТНИКА — Удаление сотрудника из базы данных.
  Команды и функции:
  /humans — Выводит список пользователей, которые используют бота, с их Telegram ID.
  Отпуск — При нажатии на пункт меню Отпуск появляется список сотрудников, находящихся в отпуске, и кнопки добавить или редактировать отпуск.
  Больничные — При нажатии на пункт меню Больничные выводится список сотрудников на больничном, а также кнопка добавить или редактировать больничный.

7. **Пример испоьзования**:
  Введите пароль 549 в чат с ботом, чтобы получить доступ к функциям.
  Используйте меню для просмотра информации о сменах, сотрудниках, отпуске и больничных.
  Нажимайте на сотрудников в списках смен, чтобы увидеть их полную информацию.

8. **Лицензия**:
  Этот проект предоставляеться для общего пользования.

9. **Дополнительная информация**:
  Для использования Telegram бота необходимо создать бота в BotFather и указать полученный токен в проекте. Убедитесь, что все файлы находятся в одном репозитории, а зависимости добавлены в файл requirements.txt.
